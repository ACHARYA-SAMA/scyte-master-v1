# iso

The Anatomy kit (MIT, © 2026 Ryan, https://github.com/wheresryan22/anatomy), copied in as it ships (only a lint header added to `react/live.tsx`): the isometric camera, solids and parts library (`iso-kit.ts`), its styles (`iso.css`), and the React components (`react/`). The home page's recovery machine (`src/components/figures/recovery/`) is drawn with it.
